# Career Twin

Career Twin is an AI-powered career assistant that helps users build, manage, and optimize their professional journey.

## Features

- AI-powered Career Twin profile
- Resume and cover letter generation
- Job tracking
- Interview preparation
- Career dashboard
- Next.js + React + TypeScript

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the application.
